Where the change travels

Red fingerprints trace the path from each changed record up to the root.

How to demo it
  1. Press Create baseline. The current data is now the trusted version.
  2. Edit one line. The banner turns red and names the record, and the red path leads to the root.
  3. Press Restore text to baseline. It goes green again.
  4. Press Save baseline file, then change a line again.
  5. Press Load baseline file and pick the saved file. Your data is checked against it and shows red.
  6. Use Accept current data as new baseline only when you really want the changes to become the trusted version.
